## 功能特性

### 日程同步与保护

- 按设定间隔拉取 Looki Moments 中已经结构化的时间片段，并向前回填指定天数。
- SQLite 本地持久化，WAL 模式；同步带互斥锁，避免重复任务同时写入。
- 保存标题、关键词、描述、音频摘要、媒体类型、采集模式和起止时间；兼容 UTC 时间并转换到配置时区。
- 有稳定 Looki ID 时幂等去重；缺少稳定 ID 时使用内容键辅助识别。
- 手工补录、手工编辑和对话校正独立保存，后续同步不会静默覆盖。
- 删除采用墓碑标记，远端再次同步不会把已删除记录复活。
- Looki 尚未生成结构化数据时，提高轮询频率也不会让数据提前出现。

<br />

### Looki AI 日志与任务

- 同步 Looki 已生成的 AI 日志（日记、昨日回顾、音频总结等），全部由规则代码处理，不调用任何模型。
- 音频总结按 `recorded_at` 与日程结束时间精确对齐；无法可靠匹配的日志不猜测时间段，统一放在当天时间轴最底部。
- 已匹配日志显示在对应时段内容底部，只标注“Looki AI 总结”，不保留日志原始大标题。
- 任务支持 `- [ ]`、`* [ ]`、`+ [ ]` 及对应 `[x]` / `[X]` 复选框，也可从“任务、待办、建议、计划”等明确区域中的列表和编号项提取；普通知识内容里的编号列表不会被当作任务。
- 任务聚合页分组展示未完成、本日完成和已删除任务；完成日期按实际勾选时间统计，括号内保留提出日期。
- 日视图左侧显示当天未完成任务，可定位到对应时段或日志并直接勾选完成；任务页支持编辑、排序、软删除和恢复。
- 日程正文、AI 总结、任务与纠正可在页面编辑；用户编辑优先于后续 Looki 同步，在 Markdown 中删除任务标记会物理删除对应任务。
- 已删除任务不进入模型上下文、不参与提醒，默认也不在任务聚合页显示；当日日程正文保留删除线。
- 可单独关闭页面上的日志展示（不影响同步与任务状态）；任务提醒由当前默认对话模型筛选值得跟进的事项，并按接收人会话选择的人格生成 Bot 自己的话术。
- 每个接收人按独立提醒间隔最多收到一条提醒，每轮只选择最有价值的一项任务；生成提醒时会参考该任务的来源日志，低价值任务可自动软删除，已有提醒记录或被其他接收人选中的任务不会误删。
- 提醒接收人可在私聊回复“完成了”“搞定了”等明确短句，将最近一次提醒且未完成的任务标为完成；找不到可完成任务时不拦截正常聊天。

<br />

### 对话与图片

- `query_looki_schedule`：按日期范围和关键词查询原始日程、媒体类型及校正历史。
- `add_looki_correction`：管理员为日程追加对话校正，不修改 Looki 原始内容。
- `send_looki_image`：按严格时段或活动语义找图，由多模态模型挑选一张，再发送原图或图生图结果。
- 支持白名单成员和白名单群；对话校正写入仅面向 AstrBot 管理员，近期线索范围由 `clue_scope` 控制。

## 快速开始

1. 将本仓库放入 AstrBot 的 `data/plugins/` 目录，或通过支持的插件安装方式安装。
2. 在 AstrBot 控制台启用插件。
3. 填写 `looki_api_key`。插件使用 `x-api-key` 请求头访问 Looki 开放 API。首次连接时，插件页面会询问是否导入历史日程；选择“暂不导入”后也可随时手动同步。
4. 保持 `auto_sync` 开启，或在插件页面点击“立即同步”。
5. 打开插件页面，确认日程已经落库。
6. 如需图片功能，配置支持图像输入的挑图模型；只发原图时开启 `image_send_original`，无需配置图生图模型。

Python 依赖：

```text
httpx>=0.27.0,<1.0.0
pydantic>=2.0.0,<3.0.0
Pillow>=10.0.0,<13.0.0
```

视频抽帧还需要系统提供 `ffmpeg` 和 `ffprobe` 命令。只同步日程或处理图片时不需要它们；官方 AstrBot Docker 镜像通常已包含这两个命令。

## 对话工具与权限

| 工具                     | 作用                         | 写入权限          |
| :--------------------- | :------------------------- | :------------ |
| `query_looki_schedule` | 按日期范围和关键词查询原始日程、媒体摘要与校正历史。 | 只读            |
| `send_looki_image`     | 按严格时段或活动语义找图、选图并发送。        | 只读日程，按需发送图片   |
| `add_looki_correction` | 为唯一确认的日程追加对话校正。            | 仅 AstrBot 管理员 |

权限分两层：

1. **插件访问层**：私聊查询默认开放；群聊由 `allow_group_query`、成员白名单或群白名单任一条件放行。白名单独立生效，无需打开群聊总开关。
2. **AstrBot 工具权限层**：控制台“扩展 → 组件”中的工具仍可分别设置为管理员、成员或停用，实际可用范围取两层权限的交集。

**私聊查询默认不限定管理员**：任何能与机器人私聊的人，都可能通过日程、日志和图片工具读取你的个人生活数据。面向公众提供机器人服务前，请在 AstrBot 组件权限中把这些工具限制为管理员，或确认所有私聊用户都可以访问这些数据。

`add_looki_correction` 始终只面向 AstrBot 管理员；近期线索注入按 `clue_scope` 单独判断。

### 查询日程

- 支持日期范围、可选关键词和返回上限。
- 关键词会匹配标题、关键词、描述、音频摘要和对话校正，并进行大小写、标点与空白归一化。
- 原始内容与校正冲突时，应以最新校正为准；描述仍只是线索，不应被解释为确定的健康或行为结论。

### 对话校正

管理员可以先查询并定位唯一日程，再追加校正。例如：

```text
实际地点是教室，不是宿舍。
```

校正按时间保留多条历史，不修改 Looki 原始描述。无法确定唯一记录时，不应写入。

## 近期线索注入与对话校正

`clue_scope` 支持“关闭”“仅对管理员私聊开放”“仅对白名单用户/群启用”和“所有人”。默认只在管理员私聊提供少量近期背景；白名单模式复用成员与群白名单，设为“关闭”则完全不注入。

近期线索优先列出回看范围内**已结束**的真实活动，按开始时间从近到远，包含日期、起止时间、标题、来源（Looki 记录或手工补录）和简短描述；剩余名额再放对话校正、晚间与关键词统计。数量由 `clue_days` 与 `max_clues` 控制。

注入时会注明最近成功同步时间，并说明 Looki 处理后可能有延迟：这些记录是用户本人的真实经历（来自 Looki 硬件），不是 Bot 的亲身经历；不能据此推断用户此刻的状态、位置或活动结果，只作背景参考。描述保持保守，例如较晚结束的活动只会写“晚间仍有活动记录”，不会推断睡眠或健康情况。

## 图片与视频

### 两种找图方式

1. **明确时段**：提供 `date`、`start_time`、`end_time`，先只查询与该时段相交的 Looki 日程。
2. **活动回忆**：没有明确日期时只提供 `query`，例如“之前一起玩 Switch 的照片”，由插件在本地日程中定位最近匹配的活动。

明确时段的候选不足时，图片服务可以补充同日相邻活动的候选，并在返回结果中明确说明，不会静默改变查询范围。活动模式没有匹配时不会发送无关照片，也不会为了找图自动扩大远端同步范围。

### 候选、抽帧与发送

- 图片直接成为候选；每个视频最多保留 1 张 JPEG 帧。
- 照片优先：分页读取该时段的全部媒体文件（每页 50 条，最多 20 页），视频项自带的缩略图也会作为照片候选，只有在照片不足时才依赖视频抽帧。
- 可探测时长时，按视频长度选择最多 3 个时刻抽帧，经过清晰度与异常帧过滤后择优保留 1 张；无法探测时长时依次尝试第 3 秒、第 1 秒和第 0 秒。
- 视频流式下载上限为 50 MiB，单个媒体失败只跳过该候选。
- 默认准备 6 张有效候选，可配置 1–9 张；图片与视频交错分批处理，每批最多 2 路并发。
- 所有有效候选交给多模态模型，模型必须返回一个有效编号；编号无效时明确报错，不随机选图。
- 无论原图还是图生图模式，最终只发送选中的 1 张。原图模式下，视频来源发送抽帧 JPEG，不发送 MP4。

### 图生图

- 默认使用日系二次元插画风格，可修改默认提示词或在单次调用中追加调整。
- 多模态模式使用 AstrBot Provider，要求模型支持图像输入与图片输出。
- 兼容接口支持 `/images/edits`，以及使用 JSON base64 data URL 的完整 `/images/generations`，后者适用于火山 Seedream 等接口。
- 兼容接口支持返回 `b64_json` 或 `url`；图生图失败不会静默退化为无关的文生图。
- 增加候选数量、使用较慢模型或提高输出分辨率时，可能还需要调整 AstrBot 的全局工具调用超时；该设置会影响其他工具，应谨慎修改。

## 数据存储

数据库位于：

```text
data/plugin_data/astrbot_plugin_looki_companion/schedules.sqlite3
```

主要数据：

- `schedules`：原始日程、手工补录、编辑标记、软删除、采集模式和媒体类型。
- `schedule_corrections`：通过 `schedule_id` 关联的对话校正历史。
- `looki_journals`：Looki AI 日志正文、类型、录音时间、匹配状态与对应的日程 `schedule_id`。
- `looki_tasks`：从日志中提取的任务、完成状态、软删除、排序、编辑保护与提醒去重时间。
- `task_reminders`：各接收人的实际提醒原文与时间，用于提醒间隔、接收人去重、完成回复定位和后续私聊上下文。
- `sync_meta`：最近同步时间、错误与首次导入选择等元数据。

**备份**：复制整个 `data/plugin_data/astrbot_plugin_looki_companion/` 目录。不要只复制主库而忽略可能存在的 `-wal` 文件。

## 隐私说明

- 插件默认不主动发消息、不定时推送，不读取或调用其他插件的私有数据；只有开启 `enable_task_reminders` 并单独配置用户 ID 后，才会向这些人发送任务提醒。
- 开启任务提醒后，待评估任务的 ID、提出日期、所属区域、正文和最多 4000 字符的来源日志会交给当前对话模型，用于筛选和按接收人会话选择的人格生成提醒。每个接收人按独立间隔最多收到一条、只包含一项任务。默认自动软删除本轮未被任何接收人选中的低价值任务；已有提醒记录的任务不会自动删除，关闭自动删除时保留任务并允许后续重新评估。模型不可用、调用失败或输出异常时不发送、不删除、不标记，下次同步重试。
- 接收人后续私聊会携带最近一次未完成、未删除任务的提醒原文、任务正文和最多 4000 字符的来源日志，供当前对话模型理解追问；非接收人、群聊、关闭任务提醒或任务完成后均不注入。
- 完成回复只处理提醒接收人的私聊明确短句，规则在本地执行，不额外调用模型；只完成最近一次提醒且仍未完成的任务，没有匹配任务时消息继续走正常聊天流程。
- 原始 JSON 默认不写入数据库；开启 `store_raw_json` 后也仅供本地调试，Web API 不返回该字段。
- 私聊查询默认不限定管理员；公众 Bot 应结合 AstrBot 组件权限限制日程、日志与图片工具的使用者。
- WebUI 读写通过 AstrBot 插件页面认证 bridge 调用，匿名请求返回 401。
- 使用图片工具时，候选图片或视频帧会发送给挑图模型；图生图时，选中的参考图和提示词会发送给图生图服务。
- 图片和视频不写入 SQLite。候选图、下载的视频和生成图使用独立临时目录，固定保留 3 天，并在插件启动及图片调用时清理过期文件。
- 白名单只放开读取与图片工具，不开放对话校正写入；是否注入近期线索由 `clue_scope` 决定。

## 常见问题

### 同步成功但没有新数据

Looki 可能尚未生成对应日期的结构化片段，或记录缺少有效 ID、日期、起止时间、标题。插件不会用猜测内容填补缺失日程。

### 我修改过的日程会被远端同步覆盖吗

不会。用户编辑有独立标记，远端同步会保留手工修改。手工补录和软删除也有相应保护。

### 群里无法查询日程

默认关闭群聊访问。可开启 `allow_group_query`，或配置成员 / 群白名单；同时检查 AstrBot“扩展 → 组件”中的工具权限。

### 视频为什么不能抽帧

请确认运行环境中 `ffmpeg` 和 `ffprobe` 可直接执行，并检查视频是否超过 50 MiB、下载地址是否已失效。单个媒体失败不会阻断其他候选。

## 目录结构

```text
astrbot_plugin_looki_companion/
├─ main.py                  # 插件入口、同步、对话工具与 Web API
├─ schedule_store.py        # SQLite、迁移、日程、日志与任务
├─ journal_service.py       # Looki AI 日志解析、时段匹配与任务提取
├─ image_service.py         # 找图、视频抽帧、多模态选图与图生图
├─ intent_service.py        # 对话意图识别与指代承接（纯规则）
├─ life_search_service.py   # 本地活动检索与匹配打分
├─ _conf_schema.json        # AstrBot 配置定义
├─ metadata.yaml            # 插件元信息
├─ requirements.txt         # Python 依赖
├─ pages/
│  └─ schedule/
│     ├─ index.html         # 日程、任务、纠正与设置页面
│     └─ vendor/            # 本地 Marked / DOMPurify 及其上游许可证
└─ tests/
   ├─ fixtures/             # 脱敏的 Looki 字段形状样例
   ├─ test_looki_parse.py
   ├─ test_schedule_store.py
   ├─ test_image_service.py
   ├─ test_intent_service.py
   └─ test_life_search.py
```

## 兼容性

- 元信息声明 AstrBot `>=4.23.1`。
- Python `>=3.10`。
- 当前声明支持平台：`aiocqhttp`；其他平台未在元信息中声明，也未逐一验证。
- 视频功能额外依赖系统 `ffmpeg` / `ffprobe`，其余核心日程功能不依赖它们。
